# Трекер полезных привычек (Backend)

Бэкенд-часть SPA веб-приложения для приобретения полезных привычек и искоренения плохих, разработанная по мотивам книги Джеймса Клира «Атомные привычки».

## Стек технологий
* **Python** 3.14+
* **Django** / **Django REST Framework (DRF)**
* **PostgreSQL** (База данных)
* **Celery** + **Redis** (Периодические задачи и брокер сообщений)
* **Simple JWT** (Авторизация по токенам)
* **Docker** / **Docker Compose**
* **Flake8 / Black / Isort** (Линтинг и форматирование кода)

## Особенности проекта
-  **CORS настроен**: Разрешенные домены вынесены в конфигурацию.
-  **Авторизация**: Реализована кастомная авторизация пользователей по Email и JWT-токенам.
-  **Валидаторы**: Реализованы 5 жестких бизнес-валидаторов для моделей привычек.
-  **Пагинация**: Настроена выдача списков по 5 привычек на страницу.
-  **Права доступа**: Реализован пермишен `IsOwner` для CRUD-операций, публичные привычки доступны только для чтения.
-  **Telegram Интеграция**: Настроена отправка напоминаний через бота по расписанию Celery Beat.
-  **Покрытие тестами**: Покрытие кода тестами составляет **>80%** (файл задач Celery покрыт на 100%).
-  **Документация**: Автоматическая генерация документации через Swagger и ReDoc.

## Установка и запуск проекта

### 1. Клонирование репозитория
```bash
git clone <ссылка_на_ваш_репозиторий>
cd course-work-5
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге на основе шаблона `.env.template`:
```bash
cp .env.template .env
```
Заполните в `.env` параметры подключения к PostgreSQL, Redis и ваш `TELEGRAM_TOKEN`.

### 3. Установка зависимостей через Poetry
```bash
poetry install
poetry shell
```

### 4. Применение миграций
```bash
python manage.py migrate
```

### 5. Запуск сервера разработки
```bash
python manage.py runserver
```

### 6. Запуск Celery (в отдельных терминалах)
Запуск воркера:
```bash
celery -A config worker --loglevel=info
```
Запуск планировщика задач (Beat):
```bash
celery -A config beat --loglevel=info
```

## Тестирование и проверка качества кода

Для запуска автотестов и просмотра отчета о покрытии кода выполните:
```bash
coverage run --source=habits manage.py test habits
coverage report
```

Для проверки соответствия кодовой базы стандарту PEP 8:
```bash
flake8 .
```
